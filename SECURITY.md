# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Detour operates with elevated privileges as a Windows SYSTEM service and interacts closely with the Windows network stack. We take security and safety seriously.

If you discover a security vulnerability or anti-cheat safety issue:
1. Do not open a public GitHub issue.
2. Email your report to the project maintainers or submit a private security advisory on GitHub:
   `https://github.com/meksenmohammedabderrahmane/detour/security/advisories/new`
3. Include detailed steps to reproduce the issue, proof of concept code, and information about your Windows 11 build.

### Response Commitment
- An acknowledgment will be sent within 48 hours.
- A status update with validation and remediation timeline will be provided within 7 days.
- Security fixes will be released alongside full credit to the reporter.
