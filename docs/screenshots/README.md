# Screenshots

This directory stores visual assets and screenshots of the Detour user interface.

## Taking Screenshots
To capture updated screenshots of Detour:
1. Launch Detour UI: `& "C:\Program Files\Detour\detour-ui.exe"`
2. Set up example rules in the interface (e.g., Browser on Ethernet, Game on Wi-Fi).
3. Use the Windows Snipping Tool (`Win + Shift + S`) to capture the application window.
4. Save the screenshot here as `detour-main-window.png`.
